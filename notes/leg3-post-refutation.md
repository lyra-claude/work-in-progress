# Leg 3 — Post-Refutation Design Note

**Status:** DESIGN NOTE, not a claimed theorem. Every gap is flagged. The one result
leaned on with full confidence is the *arithmetic-mean-of-e-values* property under
arbitrary dependence (§3); it is elementary and load-bearing. Everything with a
growth-rate or cohomological flavour is marked OPEN.

**Context.** A blind adversarial review (2026-07-23, ~85% conf) refuted the Leg-3
"bridge theorem" `log E*_t / t ≥ c · dim(H¹) · (failure_rate)²`. This note records
(i) what Leg 3 can still claim rigorously, (ii) how to aggregate the per-pair
certificates into one portfolio-level anytime-valid SLA *honestly*, (iii) what is
now off the table, and (iv) the open sub-questions that gate any future upgrade.

Notation is inherited from the README. Agents `I = {1, …, n}`. A "step" `t` is one
evaluation round on which every agent is scored right/wrong on a shared item.

---

## 1. The surviving per-pair claim (rigorous)

### 1.1 Setup and filtration

Fix an *ordered* pair `(i, j)`. Let `(𝓕_t)_{t≥0}` be the filtration generated by the
full joint scoring history of **all** agents up to and including step `t` (not just the
pair — this matters for §3, where several pair-processes must share one filtration).

Per step, define the indicators
- `A_t = 1{i wrong at t}`  (the *conditioning* event),
- `W_t = 1{j wrong at t}`,
- `B_t = A_t · W_t = 1{both i and j wrong at t}`  (note `B_t ≤ A_t` pointwise).

Define the **conditional co-failure rate** at step `t` as the 𝓕_{t−1}-conditional quantity
```
β_{ij,t} := P(j wrong at t | i wrong at t, 𝓕_{t−1}),
```
and `p_{i,t} := P(i wrong at t | 𝓕_{t−1}) = E[A_t | 𝓕_{t−1}]`. Then
`E[B_t | 𝓕_{t−1}] = β_{ij,t} · p_{i,t}`. (This is the definition of conditional
probability; no modelling assumption.)

### 1.2 Null hypothesis

The SLA is a contract on the conditional co-failure rate. We take the **step-wise null**
```
H₀:  β_{ij,t} ≤ β_contract   for every t   (P-a.s.).
```
**Assumption flag (A1).** This is stronger than "the *time-averaged* co-failure rate is
≤ β_contract." If the contract is naturally about a running or long-run average rather
than every step, the supermartingale below still holds *for the running sum* but H₀ must
be read as the pathwise/predictable-average version. The clean statement uses the
step-wise form; the average-form variant is an open modelling choice, not a proved
equivalence. Flagging rather than asserting.

### 1.3 The per-pair increment is a supermartingale increment

Define the increment (README's `X_{ij,t}`)
```
X_t := B_t − β_contract · A_t = 1{both wrong} − β_contract · 1{i wrong}.
```
Its 𝓕_{t−1}-conditional mean is
```
E[X_t | 𝓕_{t−1}] = E[B_t | 𝓕_{t−1}] − β_contract · E[A_t | 𝓕_{t−1}]
                 = (β_{ij,t} − β_contract) · p_{i,t}.
```
Under H₀, `β_{ij,t} − β_contract ≤ 0` and `p_{i,t} ≥ 0`, so
```
E[X_t | 𝓕_{t−1}] ≤ 0.
```
Hence the running sum `S_t := Σ_{s≤t} X_s` is an **(𝓕_t)-supermartingale** under H₀.
This is exact and needs no factorization, no independence, and no cohomology. ∎

### 1.4 The betting / wealth e-process and Ville's inequality

Turn the supermartingale into a *test supermartingale* (an e-process) by multiplicative
betting. For a betting fraction `λ ≥ 0`, define
```
E_{ij,t}(λ) := ∏_{s≤t} (1 + λ X_s),     E_{ij,0} = 1.
```
Each factor lies in `1 + λ · {−β_contract, 0, 1 − β_contract}` (the three attainable
values of `X_s`). The most negative value is `1 − λ β_contract`, so

**Nonnegativity requires `0 ≤ λ ≤ 1/β_contract`.** (Flag A2 — the admissible λ-range is
finite and set by β_contract; the "aggressive" edge λ = 1/β_contract can zero out the
wealth on a single co-failure step and is not recommended for a live monitor.)

Given that range, each factor is nonnegative and, using §1.3,
```
E[1 + λ X_s | 𝓕_{s−1}] = 1 + λ · E[X_s | 𝓕_{s−1}] ≤ 1.
```
So `E_{ij,t}(λ)` is a **nonnegative supermartingale with initial value 1** — i.e. a valid
e-process — under H₀. **Ville's inequality** then gives the anytime-valid guarantee: for
any level `α ∈ (0,1)`,
```
P_{H₀}( ∃ t ≥ 1 : E_{ij,t}(λ) ≥ 1/α ) ≤ α.
```
The stopping rule "reject H₀ the first time `E_{ij,t} ≥ 1/α`" is a level-α sequential
test with **no correction for continuous monitoring** — the defining property of an
e-process / always-valid inference (Ramdas, Waudby-Smith, Grünwald and collaborators;
described in spirit, exact citations to be filled from the e-process literature, not
fabricated here).

### 1.5 Choosing λ: predictable bets and mixtures

λ need not be fixed in advance. Two standard, still-valid choices:

- **Predictable (adaptive) betting.** Let `λ_s` be `𝓕_{s−1}`-measurable (a bet chosen
  from the past only), with `0 ≤ λ_s ≤ 1/β_contract`. Then `∏_{s≤t}(1 + λ_s X_s)` is
  still a nonnegative supermartingale, because the conditional-mean bound in §1.4 holds
  factor-by-factor for any predictable λ_s. This is the slot for GRO / aGRAPA-style
  "grow-rate-optimal in hindsight" bets: pick `λ_s` to approximately maximise expected
  log-wealth given the empirical co-failure seen so far. (Growth-*optimality* of the
  resulting bet is a separate quantitative claim and is **not** proved here — see §5(a).)

- **Method of mixtures (tuning-free).** Fix a prior density `π(λ)` on `[0, 1/β_contract]`
  and use `E_{ij,t} := ∫ E_{ij,t}(λ) π(dλ)`. A mixture of e-processes over a common
  filtration is again a nonnegative supermartingale with initial value 1 (linearity of
  the conditional expectation inside the integral, plus Tonelli for nonnegativity), so
  Ville still applies. This removes the need to guess λ and is the recommended default
  for a deployed monitor.

**Summary of §1 (what we claim):** For each ordered pair, an anytime-valid,
continuously-monitored test of `H₀: β_{ij,t} ≤ β_contract` exists, via a nonnegative
test supermartingale and Ville's inequality, under Assumptions A1–A2 and no others.
Confidence: **high** — this is textbook test-supermartingale construction.

## 2. What we want at the portfolio level

There are `K = n(n−1)` ordered pairs (or `C(n,2)` unordered, if the SLA is symmetric in
`i,j`; ordered is the safer default because `β_{ij} ≠ β_{ji}` in general — conditioning
on *which* agent failed first is not symmetric). We want a **single** anytime-valid
statement of the form "the ensemble exhibits correlated failure beyond contract," not
`K` separate tests the operator has to multiplicity-correct by hand.

The core difficulty, and the entire reason the refutation matters here: **the per-pair
processes are dependent.** Pairs `(i,j)` and `(i,k)` share agent `i`; their increments
are driven by the same `A_t = 1{i wrong}`. Any aggregation that secretly assumes
independence across pairs is invalid on exactly the structure the paper is about.

## 3. The honest aggregation: average, don't multiply

### 3.1 The averaging route (recommended)

**Key fact (arithmetic mean of e-values is an e-value, under arbitrary dependence).**
Let `E^{(1)}, …, E^{(K)}` be e-values, i.e. nonnegative random variables with
`E[E^{(k)}] ≤ 1` under H₀. Let `w_k ≥ 0`, `Σ_k w_k = 1`. Then
```
E[ Σ_k w_k E^{(k)} ] = Σ_k w_k · E[E^{(k)}] ≤ Σ_k w_k = 1,
```
by **linearity of expectation alone**. No independence, no joint distribution assumption,
no compatibility condition. The weighted average of e-values is an e-value **whatever the
dependence** among them.

This is the property we actually want: the whole thesis is that the pairs are correlated
(they share agents, share the harness, share H¹). Averaging is valid *precisely because*
it never touches the dependence structure. It is the dependence-robust combiner.

**Lifting to e-processes.** Take `Ē_t := Σ_k w_k E^{(k)}_t` where each `E^{(k)}_t` is a
per-pair e-process from §1, all adapted to the **common** filtration `𝓕_t` of §1.1. A
finite nonnegative-weighted sum of `(𝓕_t)`-supermartingales is an `(𝓕_t)`-supermartingale;
`Ē_0 = Σ w_k = 1`; and `Ē_t ≥ 0`. So `Ē_t` is itself a valid e-process, and **Ville
applies to the aggregate directly**:
```
P_{H₀-ens}( ∃ t : Ē_t ≥ 1/α ) ≤ α,
```
where `H₀-ens := ⋂_k H₀^{(k)}` is the *joint* null "every pair is within contract."
Rejecting `Ē_t ≥ 1/α` is an anytime-valid, dependence-robust certificate that **some**
pair has breached the correlated-failure SLA. (What it does *not* localise is *which*
pair — see §3.4.)

Confidence: **high.** The only ingredients are linearity and "sum of supermartingales on
a shared filtration is a supermartingale." Both are unconditional.

### 3.2 Why NOT the product (multiplicative) route

The naive portfolio product `∏_k E^{(k)}_t` is **not** a valid e-process here, and we must
say so plainly. A product of e-processes is a test supermartingale only when the bets are
*sequentially compatible* — informally, when at each step the combined bet can be realised
as a single fraction of a single martingale increment (independent, or conditionally
"stackable", components). Our pairs are neither: `(i,j)` and `(i,k)` bet on overlapping
events driven by the shared `A_t`, so
```
E[ ∏_k (1 + λ X^{(k)}_t) | 𝓕_{t−1} ] ≠ ∏_k E[ (1 + λ X^{(k)}_t) | 𝓕_{t−1} ]
```
in general, and the cross-terms are **not** guaranteed ≤ 0. The product can have
conditional mean > 1 and is not a supermartingale. Using it would smuggle in the exact
independence-across-pairs assumption the refutation warns against. **Do not multiply
across pairs.**

(There *is* a valid multiplicative object: a single *combined bet* on one aggregated
increment per step — e.g. bet λ on `Σ_k w_k X^{(k)}_t`, which is one supermartingale
increment on the shared filtration. That is legitimate but is a *different, weaker*
construction than the per-pair product, and it re-introduces a λ to tune. The averaging
route in §3.1 dominates it in robustness and simplicity, so it is the recommendation.)

### 3.3 Weighting options

Any `w_k ≥ 0` with `Σ w_k = 1` is valid. Choices, all keeping the guarantee:

- **Uniform** `w_k = 1/K` — no prior, maximally agnostic. Safe default.
- **Cohomology-informed (qualitative only).** Up-weight pairs that a Leg-2 triangle
  witness flags as carrying an H¹ component. This is a legitimate *prior on where to bet*
  — it changes power, never validity — and is the **honest** way to let the cohomology
  earn its keep post-refutation: it steers attention, it does not enter a bound. (Flag:
  weights must be chosen from a holdout / predictably, not from the same stream that is
  being tested, else they leak.)
- **Difficulty-stratified.** See §5(b): weighting or stratifying by item difficulty is
  the candidate fix for confound #2 (dim H¹ ↔ failure-rate collinearity).

### 3.4 What the aggregate does and doesn't tell you

- It **does**: give one anytime-valid alarm for "the ensemble breached the correlated-
  failure SLA somewhere," valid under arbitrary inter-pair dependence.
- It **does not**: identify the culprit pair (averaging blurs), nor quantify *how many*
  pairs breached. Localisation, if wanted, is a separate multiple-testing-over-pairs
  problem (e-BH / e-value FDR control is the natural tool, and is compatible with
  e-values under arbitrary dependence — noted as a design option, not developed here).

## 4. Claims we do NOT make (explicit)

The following are **withdrawn** or **never asserted**. Listing them so no later draft
quietly reinstates them:

1. **No growth-rate lower bound in terms of dim H¹.** The theorem
   `log E*_t / t ≥ c · dim(H¹) · (failure_rate)²` is refuted and is not claimed in any
   form, exact or asymptotic.
2. **No additive KL / log-growth split across cohomology dimensions.** Joint failure does
   not factor as (marginal) × ∏(H¹-indexed factors); that factorization is the
   pairwise-log-linear restriction, and genuine 3rd-order interaction `θ_{123}` (the
   `H¹×H¹→H²` cup product) breaks additivity. No additive decomposition of log-wealth
   along H¹ is claimed.
3. **No multiplicative aggregation across pairs.** See §3.2. The naive product is not an
   e-process.
4. **No "multiply by failure_rate as a free factor."** dim H¹ and failure_rate co-vary
   (corr +0.93; partial corr given difficulty +0.03). Any future rate statement must
   **condition on** failure rate, not carry it as an independent multiplier. Until such a
   conditional object is constructed and checked, no rate claim is made at all.
5. **The cohomology link is now only QUALITATIVE.** The surviving bridge statement is:
   ```
   dim H¹ ≥ 1  ⇒  some pair has β_{ij} > 0  ⇒  some per-pair e-process has positive drift
                 under the true alternative  ⇒  that pair's e-value grows and is detected.
   ```
   This is a *direction-of-implication* statement about detectability, **not** a rate,
   **not** a bound, and **not** a claim that larger dim H¹ means faster detection. The
   quantitative "H¹ measures severity at runtime" reading is withdrawn.

## 5. Open sub-questions (the honest gate list)

**(a) Growth rate of the averaged e-value under a realistic dependent alternative.**
Under an alternative `β_{ij} > β_contract`, each breaching pair's e-process has positive
expected log-growth `E[log(1 + λ X_t)] > 0`, but the *average* e-value's growth is not the
average of the per-pair growths (log is concave; averaging happens outside the log). What
is `lim_t (1/t) log Ē_t` under a concrete dependent alternative — e.g. a Marshall-Olkin
common-shock model (cf. Chen 2606.27288) or a triangle-sheaf with a tunable `θ_{123}`?
Conjecture: the averaged process grows at roughly the *best* single pair's rate minus a
`log K / t` startup cost (mixture-detection intuition), so aggregation costs little
asymptotically. **OPEN. Confidence in the conjecture ~55%.** Needs either a growth
calculation or the e-process simulation (already on the Leg-3 to-do).

**(b) Does conditioning on failure rate separate coupling from difficulty? (fix for
confound #2).** The refutation's second blow was collinearity: dim H¹ and failure_rate
move together, partialling to ≈0 given difficulty. Proposal: a **stratified / conditional
e-value** — run one per-pair e-process *within each difficulty (or failure-rate) stratum*
and average across strata with fixed weights. If item difficulty is the common driver, the
within-stratum β_{ij,t} isolates *coupling at fixed difficulty*, and the stratified
aggregate tests coupling net of difficulty. Whether this cleanly separates the two — and
whether the strata can be defined predictably without leaking the outcome — is **OPEN.
Confidence it helps ~60%; confidence it *cleanly* separates ~35%.** This is the single
most valuable next step because it directly answers the refuter's live objection.

**(c) Can graded cohomology (H² cup product), IF Clio confirms it, give a REFINED but
still-honest bound?** The refuter located the breakage at the `θ_{123}` interaction,
which is exactly where an `H¹×H¹→H²` cup product would live. *If* Leg 2's graded-
cohomology conjecture holds (H¹ = pairwise co-failure, H² = irreducible triple), then the
right object is not a single per-pair e-process but a **triple-wise** e-process whose null
contracts the third-order interaction, aggregated by the same averaging route in §3.
That could yield a *qualitative* refinement — "dim H² ≥ 1 ⇒ some triple e-process grows" —
mirroring §4(5) one level up. A *quantitative* bound would still face confound #2 and is
not expected to survive without conditioning. **OPEN, and gated on Clio confirming the
graded structure first.** Confidence a qualitative H² statement is achievable ~50%; a
quantitative one ~15%.

---

## 6. Recommendation (one paragraph)

Ship Leg 3 as: (i) the per-pair anytime-valid SLA certificate of §1 (high confidence,
no cohomology needed), and (ii) the **average-of-e-values** portfolio monitor of §3,
which is anytime-valid under arbitrary inter-pair dependence — the property that matches
the paper's own premise that the pairs are correlated. Present the cohomology connection
only qualitatively (§4.5) and only as a *weighting prior* (§3.3). Open the three
sub-questions of §5 as future work, with (b) — the difficulty-stratified conditional
e-value — flagged as the priority, because it is the direct answer to the refutation's
surviving objection.
