# Reliable ≠ Independent

A practitioner essay (evaluation audience). Thesis: teams measure whether an
LLM-judge panel is *reliable* (inter-rater agreement, Krippendorff α ≥ 0.80)
but that is a within-judge axis; what a panel is *for* is between-judge
*independence*, measured by the effective number of judges `n_eff` (≈ 2 even
for a nine-judge, seven-family panel; Kohli 2605.29800). Pegged to the FTC/METR
inquiry (30 Sep 2026): "independently evaluated" as a factual representation a
regulator will now ask you to defend.

Distinct from the loop-engineering essay "The Effective Two"
(`model-monoculture-essay/`), which hangs the same `n_eff` core on Lusser's law
for the harness-engineering crowd. This piece is shorter, news-pegged, and
built around the Krippendorff-α contrast.
